# SVM Core

A simple personal introduction website built as a first portfolio project. It shares a little about me, the things I’m interested in, and the ideas I try to live by, all in a clean monochrome style.

## Live Demo

Visit the site: [svm-core.vercel.app](https://svm-core.vercel.app/)

## Features

- Personal introduction and about section
- Interests and personal philosophy sections
- Black, grey, and white visual theme
- Responsive layout for different screen sizes
- Lightweight static site made with HTML, CSS, and JavaScript

## Technologies

- HTML
- CSS
- JavaScript
- Vercel for deployment

## Run Locally

No build step is required. To view the site locally:

1. Download or clone this repository:

   ```bash
   git clone https://github.com/SVMe236/svm-core.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Deployment

This project is hosted on Vercel. The live site is available at [https://svm-core.vercel.app/](https://svm-core.vercel.app/). To publish your own changes, push them to the connected GitHub repository and use the Vercel project settings to deploy the repository.
